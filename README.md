# Telegram-бот для скачивания видео

Присылаешь боту ссылку на видео из X (Twitter), TikTok, YouTube или Xiaohongshu (RedNote), он присылает видео.

- Качество по умолчанию 720p. Если файл больше 50 МБ (лимит Telegram), бот пробует 480p, затем 360p. Если и 360p не влезает, бот так и пишет.
- Работает в личных сообщениях и в группах.
- Отвечает только тем, кого ты разрешила (белый список).
- Построен на Python 3, aiogram 3, yt-dlp и ffmpeg.

## Что в архиве

| Файл | Для чего |
|---|---|
| `bot.py` | Код бота |
| `requirements.txt` | Python-зависимости |
| `.env.example` | Шаблон настроек (копируется в `.env`) |
| `README.md` | Эта инструкция |

Файл `.env.example` начинается с точки, поэтому файловые менеджеры могут его скрывать (в терминале его видно командой `ls -a`). Если он при переносе превратился в `_env.example`, это тот же файл, просто с другим именем. Файл `.env` с твоим токеном в архив не входит, его нужно создать самой.

## 1. Установка с нуля (Ubuntu, в том числе в VirtualBox)

### 1.1. Интернет и VPN в виртуалке

- В настройках виртуалки (**Settings → Network**) должен стоять адаптер **NAT**.
- Если Telegram, TikTok или другие сервисы не открываются без VPN, включи VPN **на основном компьютере**. Виртуалка в режиме NAT выходит в сеть через процесс VirtualBox, поэтому она пойдёт через VPN автоматически.
- Если у твоего VPN включён режим «только для выбранных приложений» (split tunneling), добавь в него процесс виртуалки: `VirtualBoxVM.exe` на Windows (или `VBoxHeadless.exe`, если виртуалка запущена без окна), `VirtualBoxVM` на Mac и Linux.
- Проверка из Ubuntu:

```bash
curl -I https://api.telegram.org
```

Если в ответе есть строка `HTTP/...` (даже с кодом 302 или 404), Telegram доступен.

### 1.2. Системные пакеты

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip ffmpeg curl unzip
```

### 1.3. Файлы бота и виртуальное окружение

Распакуй архив, например в `~/videobot`, и перейди в папку (если в пути есть пробелы, например `~/Рабочий стол/videobot`, заключай его в кавычки):

```bash
cd ~/videobot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Признак, что окружение включено: в начале строки терминала стоит `(venv)`. Если его нет, команда `python` не найдётся. Включать окружение нужно в каждом новом терминале (`source venv/bin/activate`).

### 1.4. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Выбери имя и username (должен заканчиваться на `bot`).
3. Скопируй токен, который пришлёт BotFather.

### 1.5. Настрой `.env`

```bash
cp .env.example .env
nano .env
```

Если файла `.env.example` нет (при переносе он мог переименоваться в `_env.example`), проверь `ls -a` и скопируй под нужным именем (`cp _env.example .env`) либо создай `.env` вручную:

```
BOT_TOKEN=сюда_токен_от_BotFather
ALLOWED_USER_IDS=
ALLOWED_CHAT_IDS=
COOKIES_FILE=
```

В значениях не должно быть пробелов вокруг `=` и кавычек. Сохранение в nano: Ctrl+O, Enter, затем Ctrl+X.

### 1.6. Первый запуск и твой ID

```bash
python bot.py
```

В терминале должна появиться строка «Бот запущен». Терминал закрывать нельзя, пока бот должен работать. В Telegram открой своего бота, нажми «Start» и отправь команду `/id` (без пробела). Бот ответит твоим ID. Останови бота (Ctrl+C), впиши ID в `ALLOWED_USER_IDS` в `.env` и запусти снова. Теперь пришли ссылку, и бот пришлёт видео.

Важно: после любого изменения `.env` или `bot.py` бота нужно перезапускать.

## 2. Cookies: когда нужны и как мы их включали

Cookies нужны не всегда. Пока всё скачивается, их можно не использовать. Они нужны, если:

- YouTube пишет, что нужно «подтвердить, что вы не бот»;
- видео приватное или требует входа;
- не качается Xiaohongshu (без входа в аккаунт он часто не отдаёт видео).

### 2.1. Как получить cookies из Яндекс Браузера

1. Яндекс Браузер работает на движке Chrome, поэтому в него ставятся расширения из магазина Chrome. Найди и установи расширение **Get cookies.txt LOCALLY**.
2. Зайди на нужный сайт (youtube.com или xiaohongshu.com) и убедись, что ты там вошла в аккаунт. Для Xiaohongshu вход возможен по QR-коду из приложения.
3. Для YouTube лучше использовать **инкогнито-окно** (Ctrl+Shift+N): войди в аккаунт там и сразу экспортируй cookies. Иначе YouTube быстро обновляет cookies, и файл перестаёт работать. Для этого расширение нужно разрешить в режиме инкогнито в `browser://extensions`.
4. Нажми на значок расширения (меню с пазлом) и выбери **Export** (формат Netscape). Файл сохранится в «Загрузки».
5. Повтори для второго сайта.

### 2.2. Объединение cookies разных сайтов

Cookies разных сайтов лежат в одном файле, а yt-dlp сам берёт для каждой ссылки только подходящие. Если ты выгрузила их отдельно (`yt.txt`, `xhs.txt`), объедини:

```bash
cat yt.txt xhs.txt > cookies.txt
```

### 2.3. Как подключить файл

1. Положи `cookies.txt` в папку бота (рядом с `bot.py`).
2. В `.env` укажи `COOKIES_FILE=cookies.txt`.
3. Перезапусти бота.

Если указанного файла нет по этому пути, бот молча игнорирует настройку. Проверка:

```bash
ls -l cookies.txt
grep COOKIES_FILE .env
```

### 2.3.1. Как доставить файл в виртуалку

Бот работает внутри Ubuntu, а cookies выгружены на основном компьютере. Способы:

- Через общую папку или общий буфер обмена VirtualBox (раздел 4): открой файл в блокноте, скопируй текст, в виртуалке `nano cookies.txt` и вставь (Ctrl+Shift+V в терминале).
- Без переноса: войти на нужные сайты в браузере внутри Ubuntu (там обычно Firefox) и выгрузить cookies командой, запущенной в папке бота (VPN при этом должен быть включён):

```bash
yt-dlp --cookies-from-browser firefox --cookies cookies.txt "ССЫЛКА_НА_ВИДЕО_НУЖНОГО_САЙТА"
```

### 2.4. Безопасность cookies

Cookies дают доступ к аккаунтам. Не отправляй файл никому, не публикуй, а для YouTube используй отдельный второстепенный аккаунт. Если бот работает в группе или у друзей, их запросы тоже идут через твои cookies.

## 3. Особенности отдельных сервисов (что мы исправляли)

### TikTok

Ошибка вида `[TikTok] ...: Unexpected response from webpage request` означает, что TikTok показывает антибот-проверку. Помогло «притворство браузером»:

- в `requirements.txt` стоит `yt-dlp[default,curl-cffi]` (модуль curl-cffi нужен для этого);
- в коде для ссылок tiktok.com включается `impersonate: chrome`.

Если ошибка вернётся: обнови yt-dlp (раздел 7), смени страну в VPN или подключи cookies tiktok.com.

### Xiaohongshu (RedNote)

Короткие ссылки `xhslink.com` могли перенаправлять на страницу входа `.../login?redirectPath=...`, откуда yt-dlp выдавал `Unsupported URL`. Решение:

- cookies с xiaohongshu.com (раздел 2);
- в коде функция `resolve_short_url` достаёт настоящую ссылку на видео из параметра `redirectPath`.

Проверить ссылку вручную можно командой (в папке бота, с включённым `(venv)`):

```bash
yt-dlp --cookies cookies.txt "ССЫЛКА"
```

### YouTube

- Ошибка `Failed to resolve 'www.youtube.com' (Name or service not known)` означает проблему с DNS в виртуалке, а не с ботом (раздел 5).
- Ошибка про «подтвердите, что вы не бот» лечится cookies (раздел 2).
- Если YouTube пишет про JavaScript runtime, поставь Deno и перезапусти бота:

```bash
curl -fsSL https://deno.land/install.sh | sh
```

### X (Twitter)

Работает без дополнительных настроек для публичных постов с видео.

## 4. Общая папка и буфер обмена в VirtualBox

Это нужно только для переноса файлов между компьютером и виртуалкой.

1. На основном компьютере создай папку, например `VBoxShare`.
2. В главном окне VirtualBox выбери машину → **Settings → Shared Folders** → значок «+». Укажи папку, имя (например `share`), включи **Auto-mount** и **Make Permanent**, «Read-only» не включай.
3. Установи Guest Additions в Ubuntu:

```bash
sudo apt update
sudo apt install -y build-essential dkms linux-headers-$(uname -r)
```

   Если пакеты `virtualbox-guest-utils` и `virtualbox-guest-dkms` не находятся (у нас так и было), они не обязательны. Установи Guest Additions с диска: в **окне запущенной виртуалки** (не в главном окне VirtualBox) выбери **Devices → Insert Guest Additions CD image…**, затем:

```bash
sudo mkdir -p /mnt/cdrom
sudo mount /dev/cdrom /mnt/cdrom
cd /mnt/cdrom
sudo ./VBoxLinuxAdditions.run
```

   Если заголовки ядра для твоей версии не находятся, используй `linux-headers-generic` и перезагрузи виртуалку.
4. Дай своему пользователю доступ к общей папке и перезагрузись:

```bash
sudo adduser $USER vboxsf
sudo reboot
```

   Папка появится в `/media/sf_<имя>`. Вручную её можно смонтировать так: `sudo mount -t vboxsf share ~/share`.
5. Общий буфер обмена включается в **Devices → Shared Clipboard → Bidirectional**. Он работает только после установки Guest Additions.

Не держи `venv` в общей папке (там часто не работают символические ссылки). Скопируй папку бота в домашний каталог Ubuntu и работай там.

Если пункта меню **Devices** не видно: в окне виртуалки выбери **View → Menu Bar → Show Menu Bar**, а при полноэкранном режиме нажми правый Ctrl+Home.

## 5. DNS в виртуалке (если сайты не находятся)

Проверка:

```bash
getent hosts www.youtube.com
getent hosts www.google.com
```

Если Google находится, а нужный сайт нет, задай другой DNS. Через настройки Ubuntu: **Параметры → Сеть → шестерёнка у подключения → IPv4**, выключи автоматический DNS и впиши `1.1.1.1, 8.8.8.8`. Либо командой (имя интерфейса смотри в `ip a`, часто это `enp0s3`):

```bash
sudo resolvectl dns enp0s3 1.1.1.1 8.8.8.8
```

Если не помогло, выключи виртуалку и на основном компьютере выполни `VBoxManage modifyvm "ИМЯ_ВИРТУАЛКИ" --natdnshostresolver1 on`. Также убедись, что VPN на компьютере включён.

## 6. Друзья и группы

### Доступ для друзей

1. Друг узнаёт свой ID: пишет твоему боту `/id` или открывает бота **@userinfobot** (**@getmyid_bot**) и нажимает «Start». Ещё можно переслать его сообщение боту @userinfobot, но это не работает, если у друга скрыта пересылка.
2. Впиши ID в `.env` через запятую: `ALLOWED_USER_IDS=111111111,222222222,333333333`.
3. Перезапусти бота.

### Бот в группе

1. В [@BotFather](https://t.me/BotFather): `/mybots` → твой бот → **Bot Settings → Group Privacy → Turn off**. Без этого бот в группе не видит обычные сообщения со ссылками.
2. Добавь бота в группу. Если он уже был там, удали и добавь заново, иначе настройка не применится.
3. Отправь в группе `/id`. Бот ответит ID чата (отрицательное число вроде `-1001234567890`).
4. Впиши его в `.env`: `ALLOWED_CHAT_IDS=-1001234567890` и перезапусти бота.

В группе бот отвечает **любому участнику**, молчит на сообщения без ссылок и присылает видео ответом на сообщение со ссылкой. Добавляй его только в чаты, где все свои: запросы идут через твой VPN и cookies и обрабатываются по одному.

## 7. Работа в фоне и обновления

### Запуск в фоне

Самый простой вариант: `tmux`.

```bash
sudo apt install -y tmux
tmux new -s videobot
source venv/bin/activate && python bot.py
# отсоединиться: Ctrl+B, затем D;  вернуться: tmux attach -t videobot
```

Или сервис systemd, чтобы бот стартовал сам. Создай `/etc/systemd/system/videobot.service` (замени `USER` на своё имя пользователя и поправь путь, если папка называется иначе):

```ini
[Unit]
Description=Telegram video bot
After=network-online.target
Wants=network-online.target

[Service]
User=USER
WorkingDirectory=/home/USER/videobot
ExecStart=/home/USER/videobot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now videobot
journalctl -u videobot -f    # логи
```

### Обновление yt-dlp

Сервисы часто меняются, и большинство поломок лечится обновлением:

```bash
source venv/bin/activate
pip install -U yt-dlp
```

После этого перезапусти бота.

## 8. Если что-то не работает

| Что видишь | Что делать |
|---|---|
| `python: команда не найдена` | Не включено окружение: `source venv/bin/activate` (в начале строки должно быть `(venv)`). Проверь, что в команде нет лишнего символа в конце. |
| Бот не отвечает на `/id` | Команда пишется без пробела (`/id`). Бот должен быть запущен (строка «Бот запущен»), токен без пробелов и кавычек, и ты должна писать именно этому боту. |
| `.env.example` не найден | Файл мог переименоваться в `_env.example` (`ls -a`). Скопируй его: `cp _env.example .env` или создай `.env` вручную. |
| `Failed to resolve ... Name or service not known` | DNS в виртуалке или выключен VPN (разделы 1.1 и 5). |
| TikTok: `Unexpected response from webpage request` | Обнови yt-dlp, убедись, что установлен `curl-cffi`, смени страну в VPN, подключи cookies (раздел 3). |
| Xiaohongshu: `Unsupported URL ...login...` | Подключи cookies xiaohongshu.com, используй последнюю версию `bot.py` с `resolve_short_url`. |
| YouTube просит подтвердить, что ты не бот | Cookies из инкогнито-окна (раздел 2), при необходимости Deno (раздел 3). |
| Видео слишком большое | Лимит Telegram для ботов 50 МБ. Бот сам пробует 720p, 480p, 360p. |
| Пакет не находится при `apt install` | Проверь интернет в виртуалке, выполни `sudo apt update`, включи репозиторий `universe` (`sudo add-apt-repository universe`). |
| Команда `python bot.py` падает с ошибкой импорта | Выполни `pip install -r requirements.txt` внутри окружения `(venv)`. |

## 9. Ограничения

- Лимит Telegram Bot API на отправку файла: 50 МБ. Чтобы отправлять до 2 ГБ, нужен локальный Bot API server (в этот проект он не входит).
- Бот работает, только пока включены компьютер или виртуалка, интернет и запущен скрипт.
- TikTok и Xiaohongshu защищаются от скачивания, и способы обхода быстро устаревают. Первое, что стоит делать при поломке, это обновить yt-dlp.
- Не публикуй `.env` и `cookies.txt` и не отправляй их другим людям: в них токен бота и доступ к аккаунтам. Если токен утёк, выпусти новый в @BotFather (`/revoke`).
