# Telegram-бот для скачивания видео

Присылаешь боту ссылку на видео или фото из X (Twitter), TikTok, YouTube или Xiaohongshu (RedNote), он присылает их в ответ.

- Качество видео по умолчанию 720p. Если файл больше 50 МБ (лимит Telegram), бот пробует 480p, затем 360p.
- Если и 360p не влезает, бот так и пишет.
- Бот работает в личных сообщениях и в группах.
- Бот отвечает только тем, кто есть в белом списке.
- Картинки приходят дважды: как фото (альбомом) и как файлы без сжатия.
- Переменной `ONLY_REDNOTE=1` можно отключить скачивание со всех сервисов, кроме Xiaohongshu.

Ниже инструкция, как бесплатно развернуть бота на [Render](https://render.com), чтобы он работал без твоего компьютера. Банковская карта для этого не нужна. В конце есть запуск у себя на компьютере.

## Что в папке

| Файл | Зачем |
|---|---|
| `bot.py` | сам бот |
| `Dockerfile`, `start.sh` | как собрать и запустить бота на сервере (ffmpeg и Deno уже внутри) |
| `requirements.txt` | Python-зависимости |
| `.env.example` | образец настроек (для запуска у себя) |
| `.gitignore`, `.dockerignore` | чтобы токен и cookies не попали на GitHub и в образ |

## Деплой на Render

### 0. Подготовка

1. Токен бота. Если бота ещё нет: открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и скопируй токен. Если бот уже есть, используй его токен (его можно посмотреть в BotFather: `/mybots` → твой бот → API Token).
2. Узнай свой Telegram ID. Бот сам свой ID в личке не показывает, поэтому спроси его у [@userinfobot](https://t.me/userinfobot). Либо возьми ID из своего прежнего `.env` (`ALLOWED_USER_IDS`).
3. **Останови бота на своём компьютере** перед запуском на Render. Один токен нельзя использовать в двух местах одновременно: будут ошибки `Conflict: terminated by other getUpdates request`.
4. Нужны аккаунты на [GitHub](https://github.com) и на [Render](https://render.com) (регистрируйся в Render через GitHub, так проще подключить репозиторий).

### 1. Загрузи файлы на GitHub

Создай на GitHub **приватный** репозиторий (New repository → Private), например `videobot`. Затем в папке с файлами бота:

```bash
git init
git add .
git commit -m "videobot"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/videobot.git
git push -u origin main
```

Если не хочешь возиться с git, можно загрузить файлы кнопкой **Add file → Upload files** на странице репозитория. Тогда проверь, что среди загруженных файлов есть `Dockerfile` и `start.sh`.

Файл `.gitignore` защищает от случайной загрузки `.env` и `cookies.txt`. Токен бота и cookies на GitHub попадать не должны.

### 2. Создай сервис на Render

1. В Render нажми **New +** → **Web Service** → **Build and deploy from a Git repository** и выбери свой репозиторий `videobot` (при первом разе Render попросит разрешить доступ к репозиториям на GitHub).
2. Заполни настройки:
   - **Language / Runtime:** `Docker`
   - **Branch:** `main`
   - **Region:** любой, например Frankfurt
   - **Instance Type:** `Free`
3. В разделе **Environment Variables** добавь переменные:

   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `ALLOWED_USER_IDS` | твой Telegram ID (несколько ID через запятую, без пробелов) |
   | `ALLOWED_CHAT_IDS` | необязательно, ID групп (см. ниже) |
   | `ONLY_REDNOTE` | необязательно, `1` - качать только с Xiaohongshu, остальные сервисы отключены |

4. В **Advanced** укажи **Health Check Path:** `/health`.
5. Нажми **Create Web Service**. Первая сборка занимает несколько минут.

### 3. Проверь, что всё работает

В разделе **Logs** сервиса должны появиться строки `Веб-сервер слушает порт ...` и `Бот запущен`. Открой бота в Telegram, отправь ему ссылку на видео и дождись ответа.

Названия кнопок на сайте Render могут немного отличаться от тех, что написаны здесь, они иногда меняют интерфейс.

### 4. Как дать доступ друзьям

**Вариант А: каждому по отдельности.** Каждый друг узнаёт свой числовой ID у [@userinfobot](https://t.me/userinfobot) и присылает его тебе (команда `/id` в личке с ботом не работает). Пока ID не в белом списке, бот отвечает на `/start` фразой «Извините, бот доступен только участникам тайной секты абрикосов». Впиши все ID через запятую в `ALLOWED_USER_IDS` на Render (**Environment**). После сохранения Render сам перезапустит сервис.

**Вариант Б: общая группа.** Это удобнее, не нужно собирать ID каждого:

1. Создай группу с друзьями и добавь туда бота.
2. Отключи у бота режим приватности, иначе в группе он не будет видеть сообщения со ссылками: в BotFather `/mybots` → твой бот → **Bot Settings** → **Group Privacy** → **Turn off**. После этого удали бота из группы и добавь заново, иначе настройка не применится.
3. Отправь в группе команду `/id` (она работает только у тех, чей ID есть в `ALLOWED_USER_IDS`, поэтому делай это со своего аккаунта). В ответе будет «ID этого чата», это отрицательное число.
4. Впиши его в `ALLOWED_CHAT_IDS` на Render.

Теперь любой участник группы может присылать ссылки. В группе бот молча пропускает сообщения без ссылок и с неподдерживаемыми сайтами.

### 5. Чтобы бот не засыпал

Бесплатные сервисы Render засыпают после 15 минут без обращений по HTTP, а проснуться самим бот не может. Поэтому он раз в 10 минут сам заходит на свой публичный адрес (Render выдаёт его автоматически), и этого обычно хватает.

Для надёжности можно добавить внешнюю проверку, это тоже бесплатно и без карты:

1. Зарегистрируйся на [uptimerobot.com](https://uptimerobot.com).
2. Создай монитор типа **HTTP(s)** с адресом `https://ИМЯ-СЕРВИСА.onrender.com/health` (адрес сервиса указан вверху страницы сервиса на Render) и интервалом 5 минут.

Если сервис всё-таки уснул, первое сообщение боту может ждать ответа около минуты, пока он просыпается.

### Что нужно знать про бесплатный тариф

- Бесплатный сервис Render имеет небольшие ресурсы (около 512 МБ памяти и слабый процессор), поэтому длинные видео могут скачиваться медленно. Бот качает по одному видео за раз, остальные ссылки ждут в очереди.
- Бесплатных часов в месяце (750) хватает на один постоянно работающий сервис.
- После каждого деплоя в первые секунды в логах может мелькнуть `Conflict`: старая и новая копия бота ненадолго работают одновременно. Это нормально.
- Серверы Render находятся в дата-центре, и некоторые сайты, в первую очередь YouTube, могут блокировать такие адреса. TikTok, X и Xiaohongshu должны работать без cookies. Если на YouTube появляется «подтвердите, что вы не бот», см. раздел ниже.

## Если что-то не скачивается

**Сначала перезапусти сервис.** Сайты часто меняются, и большинство поломок лечится новой версией yt-dlp. При каждом запуске бот сам ставит свежие yt-dlp и gallery-dl, так что достаточно перезапустить сервис: в Render открой сервис и выбери **Manual Deploy → Deploy latest commit** (или **Restart service**, если он есть в меню).

**YouTube просит «подтвердить, что вы не бот» или видео приватное.** Нужен файл cookies:

1. В браузере, где ты залогинен в YouTube, поставь расширение для экспорта cookies (например, «Get cookies.txt LOCALLY»).
2. Зайди на youtube.com, экспортируй cookies в формате Netscape и сохрани как `cookies.txt`.
3. В Render открой сервис → **Environment** → **Secret Files** → **Add Secret File**. Имя файла: `cookies.txt`, содержимое: всё, что внутри твоего файла.
4. Добавь переменную `COOKIES_FILE` со значением `/etc/secrets/cookies.txt` и сохрани. Сервис перезапустится.

Cookies дают доступ к аккаунту, поэтому не публикуй этот файл, не отправляй его никому и не загружай на GitHub. Для YouTube лучше завести отдельный второстепенный аккаунт. Учти, что Google может быстро отозвать такие cookies, если заметит вход с адреса дата-центра, и тогда их придётся экспортировать заново.

Для Xiaohongshu, TikTok и X cookies не нужны.

## Запуск у себя на компьютере (Ubuntu)

Пригодится для проверки или как запасной вариант.

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip ffmpeg curl unzip
```

В папке с файлами бота:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env      # впиши BOT_TOKEN и ALLOWED_USER_IDS
python bot.py
```

Для YouTube может понадобиться Deno:

```bash
curl -fsSL https://deno.land/install.sh | sh
```

После установки открой новый терминал. Не запускай бота у себя и на Render одновременно с одним токеном.

## Ограничения

- Лимит Telegram Bot API на отправку файла - 50 МБ.
- Xiaohongshu работает нестабильно, это ограничение самого сайта и yt-dlp.
- Видео не в формате H264 (редкий случай) может прийти файлом без превью, но скачать его всё равно можно.
- Из-за дата-центрового IP на Render YouTube может отказывать чаще, чем при запуске с домашнего компьютера.
